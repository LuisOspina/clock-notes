# Functional requirements

1. Local Time and UTC are always displayed at the top of the module and remain visible while saved locations scroll.
2. The user can add up to 10 locations through an Add Location dialog that searches for cities and lets the user select a result.
3. Each saved location displays its city, region/country, current time, date in `mm/dd/yyyy` format, and UTC offset.
4. Saved locations belong to the signed-in user and persist across visits.
5. A saved location can be removed with its X control; locations cannot be edited.
