# Functional requirements

1. The initial time is `00:00.00` and only the Start button is visible.
2. Start begins the timer, changes Start to Stop, and reveals Reset and Lap.
3. Stop freezes the main timer and active lap timer, and hides Lap.
4. Start resumes a stopped timer without clearing its elapsed time or laps.
5. Reset returns the timer to `00:00.00` and clears every lap.
6. The first Lap records lap 01 and begins a live lap 02.
7. Each additional Lap freezes the active lap and begins the next one.
8. The lap list is horizontally scrollable and shows three cards at a time.
